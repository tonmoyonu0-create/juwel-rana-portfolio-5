# Juwel Rana — Cybersecurity Portfolio

## Files
- `index.html` — page structure and portfolio content
- `style.css` — dark modern responsive styling
- `script.js` — mobile menu, current year, active navigation and back-to-top

## Run locally
1. Extract the ZIP.
2. Open the `juwel_rana_portfolio` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Personalise before publishing
Search the files for these placeholders and replace them:
- `your.email@example.com`
- `yourusername`
- `Your Academic Qualification`, `ADD YEAR`
- Project descriptions and skills (keep only skills you can demonstrate)
- Add real certificates only after earning them.

## Download CV
The “Download CV” section is intentionally not linked to a fake document. Add your real PDF CV and a download link when it is ready, for example:
`<a class="button button-ghost" href="assets/Juwel-Rana-CV.pdf" download>Download CV</a>`
Create an `assets` folder and place your PDF there.

## Publish
You can publish this static site using GitHub Pages. Upload these files to a public GitHub repository, then enable Pages from the repository's Settings.
